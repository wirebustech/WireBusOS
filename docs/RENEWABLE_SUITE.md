# WireBusOS Renewable Energy Tool Suite Index

WireBusOS aggregates world-class open-source tools for energy system design, grid modeling, telemetry, and hardware development. Below is the curated directory of integrated projects:

---

## ☀️ Solar PV & Irradiance
| Package | Upstream Repository | Description |
|---|---|---|
| **pvlib-python** | [`pvlib/pvlib-python`](https://github.com/pvlib/pvlib-python) | Core Python library for PV performance & irradiance modeling |
| **NREL SAM** | [`NREL/SAM`](https://github.com/NREL/SAM) | System Advisor Model techno-economic engine |
| **PySAM** | [`NREL/pysam`](https://github.com/NREL/pysam) | Python wrapper for SAM simulation engine |
| **r.sun** | GRASS GIS Module | Solar radiation raster modeling |
