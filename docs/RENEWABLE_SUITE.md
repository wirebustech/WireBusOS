# WireBusOS Renewable Energy Tool Suite Index

WireBusOS aggregates world-class open-source tools for power system modeling, renewable energy planning, engineering computation, electrical & electronics design, and spatial data engineering. Below is the curated directory of integrated projects across the core domain categories:

---

## ⚡ 1. Power-System Modelling and Analysis
| Package | Upstream Repository | Description |
|---|---|---|
| **OpenDSS** | [`electricdss/electricdss-src`](https://github.com/electricdss/electricdss-src) | Electric distribution system simulator |
| **pandapower** | [`e2nIEE/pandapower`](https://github.com/e2nIEE/pandapower) | Power flow, optimal power flow, and short circuit analysis in Python |
| **VeraGrid** | [`VeraGrid/VeraGrid`](https://github.com/VeraGrid/VeraGrid) | Open-source transmission & distribution power flow engine |
| **Matpower** | [`MATPOWER/matpower`](https://github.com/MATPOWER/matpower) | MATLAB/Octave M-file package for solving power flow and OPF |
| **PowerModels.jl** | [`LANL-ANSI/PowerModels.jl`](https://github.com/LANL-ANSI/PowerModels.jl) | Julia package for Power System Optimization formulations |
| **ANDES** | [`cuihantao/andes`](https://github.com/cuihantao/andes) | Power system dynamic simulation and DAE transient analysis |
| **GridLAB-D** | [`gridlab-d/gridlab-d`](https://github.com/gridlab-d/gridlab-d) | Agent-based electric distribution grid simulator |
