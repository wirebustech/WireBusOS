ISO Remastering Guide

Remastering WireBusOS with Cubic

Follow these chroot instructions to package the energy suite into a bootable ISO.

1

Install Cubic PPA

Add the Cubic repository to your Ubuntu 24.04 VM build environment.

sudo apt-add-repository ppa:cubic-wizard/release
sudo apt install cubic
2

Open Chroot Shell

Select Ubuntu 24.04 ISO source and launch into Cubic root terminal.

cubic
3

Run Build Script

Execute installer with --chroot flag to handle systemd & container hooks.

git clone https://github.com/wirebustech/WireBusOS.git
./build-scripts/install-wirebus.sh --chroot
4

Generate ISO

Compress squashfs filesystem and export WireBusOS-24.04-amd64.iso.

Result: WireBusOS-24.04-amd64.iso

Deploy WireBusOS Workstation

Clone the repository and provision your renewable energy engineering workstation.

git clone https://github.com/wirebustech/WireBusOS.git
cd WireBusOS && ./build-scripts/install-wirebus.sh --core
