# Scientific Python & Data Science Base Module

This module contains the foundational scientific computational stack powering all energy analysis tools in WireBusOS.

## Included Core Packages

| Package | Description |
|---|---|
| **NumPy** | High-performance N-dimensional array processing |
| **pandas** | Time-series data structures & energy profile manipulation |
| **SciPy** | Numerical integration, linear algebra, and optimization solvers |
| **matplotlib & seaborn** | Publication-quality telemetry plotting & charts |
| **JupyterLab** | Interactive notebook development environment (`wirebus-jupyter`) |

## Running the Data Science Base Test

```bash
python3 modules/12-data-science-base/datascience_suite.py
```
