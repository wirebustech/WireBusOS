# EV Charging Infrastructure & Protocols Module

This module contains open-source EV charging station software stacks, hardware firmware interfaces, and OCPP (Open Charge Point Protocol) gateways.

## Included Open Source Tools

| Tool | Upstream Repository | Description |
|---|---|---|
| **EVerest Core** | [`EVerest/everest-core`](https://github.com/EVerest/everest-core) | Open-source modular EV charging software stack for Linux |
| **OpenEVSE** | [`OpenEVSE/open_evse`](https://github.com/OpenEVSE/open_evse) | Hardware & firmware stack for EV charging stations |

## Running the EV Charging Suite Model

```bash
python3 modules/11-ev-charging/ev_charging_suite.py
```
