# GIS & Spatial Resource Assessment Module

This module contains Geographic Information Systems (GIS), spatial resource mapping, terrain analysis, and raster modeling tools for site assessment.

## Included Open Source Tools

| Tool | Upstream Repository | Description |
|---|---|---|
| **QGIS** | [`qgis/QGIS`](https://github.com/qgis/QGIS) | Desktop GIS for site assessment, land availability & resource mapping |
| **GRASS GIS** | [`OSGeo/grass`](https://github.com/OSGeo/grass) | Raster analysis, solar radiation modeling & terrain slope/aspect processing |

## Running the GIS & Spatial Suite Model

```bash
python3 modules/09-gis-spatial/gis_spatial_suite.py
```
