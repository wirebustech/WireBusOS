# Monitoring, Automation & SCADA Module

This module contains open-source home energy automation, industrial SCADA platforms, visual flow-based programming, and time-series telemetry storage.

## Included Open Source Tools

| Tool | Upstream Repository | Description |
|---|---|---|
| **Home Assistant** | [`home-assistant/core`](https://github.com/home-assistant/core) | Smart home & energy inverter integration platform |
| **OpenEnergyMonitor (emoncms)** | [`openenergymonitor/emoncms`](https://github.com/openenergymonitor/emoncms) | Energy monitoring visual logging dashboard |
| **Node-RED** | [`node-red/node-red`](https://github.com/node-red/node-red) | Flow-based visual automation for IoT sensors |
| **Grafana & InfluxDB** | Upstream Projects | Time-series metrics storage & operational dashboards |
| **ThingsBoard** | [`thingsboard/thingsboard`](https://github.com/thingsboard/thingsboard) | Enterprise IoT & SCADA telemetry platform |
| **SCADA-LTS** | [`scada-lts/scada-lts`](https://github.com/scada-lts/scada-lts) | Open source SCADA system |

## Running the Monitoring & SCADA Suite

```bash
python3 modules/06-monitoring-scada-iot/monitoring_scada_suite.py
```
