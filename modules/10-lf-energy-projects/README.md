# Linux Foundation Energy (LF Energy) Suite Module

This module contains grid calculation engines, short-term forecasting algorithms, market operations tools, and energy efficiency verification platforms maintained by the Linux Foundation Energy.

## Included Open Source Tools

| Tool | Upstream Repository | Description |
|---|---|---|
| **GridAPPS-D** | LF Energy Project | Distribution system application platform |
| **OpenSTEF** | LF Energy Project | Short-Term Energy Forecasting platform (ML load & solar forecasting) |
| **PowerGridModel** | LF Energy Project | Ultra-fast grid calculation engine in C++ and Python |
| **OperatorFabric** | LF Energy Project | Operational event management dashboard for power grid operators |
| **Assume** | LF Energy Project | Energy system forecasting & market planning framework |
| **openEEmeter** | LF Energy Project | Standardized measurement & verification (M&V) energy efficiency tool |

## Running the LF Energy Suite Model

```bash
python3 modules/10-lf-energy-projects/lf_energy_suite.py
```
