# Battery & Energy Storage Module

This module contains physics-based electrochemistry solvers, battery cell degradation tools, and open-source energy management software for battery storage deployments.

## Included Open Source Tools

| Tool | Upstream Repository | Description |
|---|---|---|
| **PyBaMM** | [`pybamm-team/PyBaMM`](https://github.com/pybamm-team/PyBaMM) | Physics-based battery modeling (Single Particle Model & DFN) |
| **OpenEMS** | [`OpenEMS/openems`](https://github.com/OpenEMS/openems) | Open energy management system for energy storage deployments |

## Running the Battery Storage Suite Model

```bash
python3 modules/04-battery-storage/battery_storage_suite.py
```
