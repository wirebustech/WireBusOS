# Power System Modelling and Analysis & Energy Planning Module

This module contains power system optimization tools, AC/DC optimal power flow (OPF) solvers, transmission & distribution analyzers, long-term energy economic planning frameworks, and dynamic transient simulators.

## Included Open Source Tools

| Category | Tool | Upstream Repository | Description |
|---|---|---|---|
| **Power System Analysis** | **OpenDSS** | [`electricdss/electricdss-src`](https://github.com/electricdss/electricdss-src) | Electric distribution system simulator |
| **Power System Analysis** | **pandapower** | [`e2nIEE/pandapower`](https://github.com/e2nIEE/pandapower) | Power flow, optimal power flow, and short-circuit analysis in Python |
| **Power System Analysis** | **VeraGrid** | [`VeraGrid/VeraGrid`](https://github.com/VeraGrid/VeraGrid) | Open-source transmission & distribution power flow engine |
| **Power System Analysis** | **Matpower** | [`MATPOWER/matpower`](https://github.com/MATPOWER/matpower) | MATLAB/Octave M-file package for power flow and optimal power flow |
| **Power System Analysis** | **PowerModels.jl** | [`LANL-ANSI/PowerModels.jl`](https://github.com/LANL-ANSI/PowerModels.jl) | Julia package for power system optimization formulations |
| **Power System Analysis** | **ANDES** | [`cuihantao/andes`](https://github.com/cuihantao/andes) | Power system dynamic simulation and DAE transient analysis |
| **Power System Analysis** | **GridLAB-D** | [`gridlab-d/gridlab-d`](https://github.com/gridlab-d/gridlab-d) | Agent-based electric distribution system simulator |
| **Energy Planning** | **PyPSA** | [`PyPSA/PyPSA`](https://github.com/PyPSA/PyPSA) | Power system analysis & optimal power flow for renewable grid transition |
| **Energy Planning** | **OSeMOSYS** | [`OSeMOSYS/OSeMOSYS`](https://github.com/OSeMOSYS/OSeMOSYS) | Open-source long-term energy planning model |
| **Energy Planning** | **Calliope** | [`calliope-project/calliope`](https://github.com/calliope-project/calliope) | Multi-scale energy system optimization framework |

## Running the Power System & Microgrid Modeling Suite

```bash
python3 modules/03-microgrid-energy-systems/grid_modeling_suite.py
```
