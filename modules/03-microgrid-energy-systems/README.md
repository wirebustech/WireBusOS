# Energy System & Microgrid Modeling Module

This module contains power system optimization tools, optimal power flow (OPF) solvers, long-term energy economic planning systems, distribution feeder simulators, and dynamic transient analyzers.

## Included Open Source Tools

| Tool | Upstream Repository | Description |
|---|---|---|
| **PyPSA** | [`PyPSA/PyPSA`](https://github.com/PyPSA/PyPSA) | Power system analysis & optimal power flow for renewable grid transition |
| **oemof-solph** | [`oemof/oemof-solph`](https://github.com/oemof/oemof-solph) | Open energy modeling framework for linear optimization |
| **Calliope** | [`calliope-project/calliope`](https://github.com/calliope-project/calliope) | Multi-scale energy system modeling framework |
| **OSeMOSYS** | [`OSeMOSYS/OSeMOSYS`](https://github.com/OSeMOSYS/OSeMOSYS) | Open-source long-term energy planning model |
| **SWITCH** | [`switch-model/switch`](https://github.com/switch-model/switch) | Power system planning and capacity expansion model |
| **Temoa** | [`TemoaProject/temoa`](https://github.com/TemoaProject/temoa) | Energy economy optimization model with uncertainty analysis |
| **GridLAB-D** | [`gridlab-d/gridlab-d`](https://github.com/gridlab-d/gridlab-d) | Agent-based electric distribution system simulator |
| **OpenDSS** | [`electricdss/electricdss-src`](https://github.com/electricdss/electricdss-src) | Electric distribution system simulator |
| **pandapower** | [`e2nIEE/pandapower`](https://github.com/e2nIEE/pandapower) | Power flow, optimal power flow, and short-circuit analysis in Python |
| **ANDES** | [`cuihantao/andes`](https://github.com/cuihantao/andes) | Power system dynamic simulation and differential-algebraic equation solver |

## Running the Microgrid Modeling Suite

```bash
python3 modules/03-microgrid-energy-systems/grid_modeling_suite.py
```
