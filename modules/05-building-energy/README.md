# Building Energy & Load Modeling Module

This module contains whole-building thermal energy simulation tools, HVAC modeling engines, and graphical building modeling interfaces.

## Included Open Source Tools

| Tool | Upstream Repository | Description |
|---|---|---|
| **EnergyPlus** | [`NREL/EnergyPlus`](https://github.com/NREL/EnergyPlus) | Whole-building energy simulation engine |
| **OpenStudio** | [`NREL/OpenStudio`](https://github.com/NREL/OpenStudio) | SDK and GUI wrapper for EnergyPlus whole-building models |

## Running the Building Energy Suite Model

```bash
python3 modules/05-building-energy/building_energy_suite.py
```
